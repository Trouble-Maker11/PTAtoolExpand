# 🏆 PTA比赛生成器 - 5分钟上手指南

## 📦 你下载的是什么？

这是一个Edge/Chrome浏览器插件，可以帮你一键从PTA平台导出比赛数据。

---

## 🚀 三步安装（超简单！）

### 第1步：解压文件
- 右键这个zip压缩包
- 选择"解压到当前文件夹"或"全部提取"
- 记住解压后的文件夹位置

### 第2步：打开浏览器扩展页面
- 打开Edge浏览器
- 在地址栏输入：`edge://extensions/`
- 按回车键

💡 如果用Chrome浏览器，输入：`chrome://extensions/`

### 第3步：加载插件
1. 找到右上角的"开发人员模式"开关，**打开它**
2. 点击"加载解压缩的扩展"按钮
3. 选择刚才解压的文件夹（里面有manifest.json文件的那个）
4. 点击"选择文件夹"

### ✅ 完成！
你应该在扩展列表看到"PTA比赛生成器"了！

---

## 🎯 如何使用？

### 准备工作：
1. 打开 https://pintia.cn
2. 用你的账号登录PTA

### 开始使用：
1. 点击浏览器右上角的插件图标（紫色图标）
2. 点击"刷新题目集列表"
3. 选择你要导出的比赛
4. 点击"生成XML文件"
5. 选择保存位置
6. 等待几分钟（取决于比赛数据量）
7. 完成！XML文件已保存

---

## ❓ 常见问题

### Q1: 我找不到"开发人员模式"开关？
**答**: 在扩展页面的右上角，是一个蓝色的开关。

### Q2: 提示"无法加载扩展"？
**答**: 
- 确保选择的文件夹里**直接包含** manifest.json 文件
- 不要选择zip文件，要先解压！

### Q3: 插件提示"未检测到登录信息"？
**答**: 
1. 先打开新标签页
2. 访问 https://pintia.cn
3. 登录你的账号
4. 再打开插件

### Q4: 生成XML需要多久？
**答**: 
- 小型比赛（几十人）：3-5s
- 大型比赛（几百人）：1-3分钟
- 请耐心等待，不要关闭浏览器

### Q5: 图标不显示/显示问号？
**答**: 不影响使用！这只是图标文件的问题。
